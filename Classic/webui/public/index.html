Access Policies

There is no need to add devices to the policy.

  • Domain forwarding rules apply to everything connected to the router.
  • When you place a device in a policy, ALL of its traffic will be redirected through the connection specified in the policy.

Creating a separate field for each domain is redundant.

  • Gather the domains into a group and give it a brief description.
  • Domains within a group are separated by a comma. Spaces are added for convenience.

Unused domains can be temporarily disabled.

  • The checkbox next to domain names is responsible for turning them on and off.
  • Instead of deleting them, you can disable them for a while and enable them when you need them again.

IP address data on special services may remain the same for some time after changes are made to HR.

  • Remember that both the browser and the operating system have a DNS cache.
  • If you doubt the result, run a tracert to make sure which route the traffic is taking to the desired domain.

Domains of the third level and higher are picked up automatically.

  • By specifying yandex.ru, all domains ending at yandex.ru will be redirected, incl. mail.yandex.ru, disk.yandex.ru, etc.

AdGuard Home

AdGuard Home does not display statistics.

  • By default, statistics are disabled because Journals take up space, turn it on in the settings:
  • Web Configurator -> Settings -> General -> "Enable log", "Enable statistics".

If you need .local domains, specify them in AdGuard Home:

  • Web Configurator -> Filters -> Rewrite DNS queries.

How to unblock a website in AdGuard Home?

  • Веб-конфигуратор -> Фильтры -> Пользовательские правила фильтрации -> Проверить фильтрацию -> ввести имя хоста ->click "Check" -> click "Unblock".
